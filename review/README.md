# Review artifacts

The screenshots and source evidence in this directory support owner review of the redesign; this directory is not served by GitHub Pages.

- `before-*`: original live website.
- `after-*`, `publications-*`, `projects-*`, `writing-*`, `life-*`: final dark redesign at desktop/mobile sizes.
- `responsive-checks.json`: 60 observed page/viewport checks.
- `publication-sources.json`: public publisher-deposited Crossref records.
- `image-generation.json`: final project illustration paths, complete prompts, and built-in tool provenance.
- `portrait-edit.json`: background-removal prompt/provenance for the supplied portrait.

The compressed, project-ready concept illustrations are in `docs/assets/images/`: `multiagent-concept.webp`, `llm-trust-concept.webp`, `skin-xai-concept.webp`, `plsem-concept.webp`, `delivery-concept.webp`, and `adaptive-ui-concept.webp`. The transparent portrait is `portrait-cutout.webp`. Their full-resolution generated originals remain in the local Codex generated-images directory; the repository uses efficient WebP assets.

Private extracted CV text, CV renderings, and asset contact sheets are ignored and excluded from commits. No website post is created from a testing fixture.
